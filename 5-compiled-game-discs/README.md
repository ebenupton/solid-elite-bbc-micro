# Compiled game disc for the Model B port of BBC Micro disc Elite

This folder contains the SSD disc image of the port, `elite-modelb.ssd`, as produced by the build process. It needs a BBC Model B with DFS and four 16K banks of sideways RAM, and boots with SHIFT-BREAK. It can be loaded into an emulator like JSBeeb or BeebEm, or into a real BBC Micro using a device like a Gotek.

The original's disc (the Stairway to Hell release), which the port is checked against, is in [4-reference-binaries/sth](../4-reference-binaries/sth).
